# FluxIDE

Web-first IDE prototype designed to become a Windows Electron desktop IDE later.

## Current system
- Monaco editor
- Persistent browser workspace
- File explorer and filtering
- Create/delete files
- 20+ language modes
- JavaScript browser runner
- Output panel
- Source-control foundation
- Update checker using `/update.json` or a configurable `localStorage` endpoint

## Netlify
Build command: `npm run build`
Publish directory: `dist`

## Roadmap
